Vault Code

ผลดีที่สุด: 0
มีตู้นิรภัย 3 ใบ แต่ละใบมีรหัสเลข 0–9 ไม่ซ้ำกัน ทายได้ใบละ 8 ครั้ง (4 หลัก) หรือ 10 ครั้ง (5 หลัก)
หลังทายแต่ละครั้ง ช่อง เขียว = ถูกตัวถูกตำแหน่ง ส่วนท้ายแถวจะบอก จำนวน เลขที่มีในรหัสแต่อยู่ผิดตำแหน่ง (ไม่บอกว่าตัวไหน) ต้องใช้ตรรกะตัดตัวเลือกเอง ทุกคำตอบควร สอดคล้องกับใบ้ที่ได้มาแล้ว

ยิ่งเปิดได้ในจำนวนครั้งน้อยและเร็ว คะแนนยิ่งสูง (ใบละสูงสุด ~900 / ~1,100) แป้นตัวเลขไม่มีสีช่วย ต้องจำเองว่าตัดเลขไหนไปแล้ว และท้ายเกมจะบอกว่าคุณทายสอดคล้องกับใบ้กี่ครั้ง
